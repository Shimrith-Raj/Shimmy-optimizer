## Shimmy Optimizer 0.9.0

**[Download Shimmy-Optimizer-Setup.exe](https://github.com/Shimrith-Raj/Shimmy-optimizer/releases/latest/download/Shimmy-Optimizer-Setup.exe)** for Windows 10/11, 64-bit.

Run it, accept the [Terms of Use](https://github.com/Shimrith-Raj/Shimmy-optimizer/blob/main/TERMS.md), and click **Yes** at the admin prompt. If SmartScreen says *"Windows protected your PC"*, click **More info → Run anyway**: the installer isn't code-signed yet.

Already on 0.5.1 or later? Open the **Updates** page and install it from there.

### More paid features from other apps, free here
- **Connections page.** Which app holds which network connection right now, TCP and UDP, IPv4 and IPv6, with the internet first. Read only: addresses are not looked up, traffic is not measured and the firewall is never touched. Export to CSV.
- **Sensor log.** Tick the readings you want and Shimmy writes them to a CSV in Downloads, every 2 seconds to 5 minutes, until you press Stop (or at 100 MB).
- **Report.** `shimmy-optimizer.exe --report`, or **Save a report** on the System page, gives a one-page summary of your PC for a bug report or a repair shop. No serial numbers, user name or addresses.

### Safer
- Shimmy's settings, history and Log move to a folder only administrators can change. Copied-in settings start with the weekly clean and automatic memory clean off, so you turn them back on yourself.
- PowerShell runs with module auto-loading off, so a module planted in your Documents folder can no longer run as administrator.
- Every delete checks the path really is where it says, with no link on the way, and "Delete permanently" covers only the files it listed.
- New files in Downloads refuse links, so nothing can trick Shimmy into overwriting a system file.
- Uninstallers and the sign-in task must sit in trusted locations.
- Uninstalling Shimmy resets a charge limit it set, and Exit lifts a "Run from the charger" hold.

### Fixes
- Settings save in one step, and one bad value no longer resets the rest.
- powercfg and PowerShell have time limits, so a stuck one can't hang a job.
- Cache totals are accurate, the Recycle Bin size is respected, and hidden items stop a folder delete.
- More code editors and terminals are protected from Clean now.
- Failed power mode changes retry, and a sampler error shows a warning instead of stopping silently.
